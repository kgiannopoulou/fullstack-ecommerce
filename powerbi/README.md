# Power BI: E-Commerce Performance Dashboard

Management reporting, not decoration: five pages, each answering one question a manager asks.

| File | Contents |
|---|---|
| [`ecommerce_analytics.pbip`](ecommerce_analytics.pbip) | Power BI project: open this in Power BI Desktop |
| [`ecommerce_analytics.SemanticModel/`](ecommerce_analytics.SemanticModel/definition) | the model in TMDL: tables, Power Query, relationships, DAX measures |
| [`ecommerce_analytics.Report/`](ecommerce_analytics.Report/definition) | the five report pages and their visuals (PBIR) |
| [`measures.dax`](measures.dax) | every DAX measure in one readable file |

PBIP is Power BI's text-based project format: it opens like a `.pbix`, but every table, measure and
visual is a readable file, so changes show up as normal diffs in git. It is generated by
[`src/build_powerbi.py`](../src/build_powerbi.py) from the same KPI definitions as the SQL and Excel.

## Data model

A star schema. Measures are calculated by DAX at query time; Power BI imports the clean
reporting tables, not pre-calculated KPI results.

```
                         DimDate (marked as date table)
                            |
     DimCustomer —— FactSales / FactOrders —— DimProduct —— FactInventoryDaily
                            |                     |
                  DimChannel · DimGeography   InventoryForecast
```

| Table | Grain | Rows |
|---|---|---:|
| FactSales | fulfilled order line | ~320k |
| FactOrders | order (incl. cancelled, for cancellation rate) | ~145k |
| FactInventoryDaily | product × day | ~257k |
| DimDate, DimProduct, DimCustomer, DimChannel, DimGeography | one row per member | |
| InventoryForecast, CohortRetention, ManagementAlerts, Anomalies, DataQualityRules, DataQualityScorecard | analysis outputs of the pipeline | |

### DAX measures (51)

| Area | Measures |
|---|---|
| Revenue & profit | Gross Sales, Discounts, Refunds, **Net Revenue**, Cost of Goods, Shipping Cost, **Gross Profit**, **Gross Margin %**, Discount Rate %, AOV |
| Time intelligence | Net Revenue PM, **MoM Growth %**, Net Revenue PY, **YoY Growth %**, Gross Profit PY / YoY %, Gross Margin PY / Change pp, Orders PY / YoY %, AOV PY / YoY % (`DATEADD`, `SAMEPERIODLASTYEAR`) |
| Customers | Customers, New Customers, Returning Customers, **Repeat Rate %**, Revenue per Customer, Returning Customer Revenue % |
| Products | Product Revenue Rank, Product Profit Rank (`RANKX`) |
| Inventory & operations | Stockout Rate %, Estimated Lost Sales, Avg Inventory Value, Inventory Turnover, Products At Risk, Revenue At Risk 30d, Refund Rate %, Cancellation Rate %, On-time Delivery % |
| Data quality | Completeness, Validity, Duplicates, Missing Values, Failed Checks |

## Pages

1. **Executive Overview**: Net revenue, gross profit, orders and AOV with YoY change; monthly revenue
   vs last year; gross margin trend; revenue and profit by category; new vs returning customers;
   top products by gross profit; **management alerts**.
2. **Sales & Product Performance**: slicers for date, country, category and product; revenue, profit,
   margin, units, growth; a **revenue vs margin scatter** (high revenue, low margin = bottom right);
   revenue rank vs profit rank per product.
3. **Customer Analytics**: customers, new, returning, repeat rate, revenue per customer; RFM segments;
   returning-customer share; **cohort retention heatmap**.
4. **Inventory & Operations**: stockout rate, inventory turnover, products at risk, estimated lost
   sales, cancellation and refund rates; the reorder table *SKU | Product | Stock | Demand | Days cover |
   Risk | Recommended action*.
5. **Data Quality**: completeness, validity, duplicates, missing values, failed checks; every
   validation rule raw vs clean; the anomaly log.

## Open, refresh, save

> **Status:** the project is generated from code and has not yet been opened in Power BI Desktop, so
> the first open may need small layout fixes. Saving it from Desktop also adds the theme files and a `.pbix`.


1. Run the pipeline so `data/cleaned/` exists: `python src/pipeline.py`.
2. Open `ecommerce_analytics.pbip` in Power BI Desktop.
3. If the repository is not at `C:\Users\konst\fullstack-ecommerce`, change the **DataFolder**
   parameter (Transform data > Manage parameters) to your `data\cleaned\` folder.
4. **Refresh**. To share a single file: *File > Save as > .pbix*.
